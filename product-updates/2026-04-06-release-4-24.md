## Introduction

Release 4.24 expanded autonomous security operations, AI ecosystem connectivity, and the completeness of DAST reporting.

---

**_New Feature_**
## AI Autonomous Pentest

- Introduced an autonomous offensive-security engine that orchestrates tools and validates attack paths.
- Added attack-chain visualization to provide transparency from reconnaissance through exploit validation.

Learn more in the [AI Pentest documentation](https://docs.convisoappsec.com/ai-capabilities/ai-pentest).

---

**_New Feature_**
## Conviso MCP Server

- Made the Conviso MCP Server available for secure AI-assisted access to Platform context.
- Enables approved AI tools to use vulnerability, asset, and project context in remediation and review workflows.

---

**_Improvements_**
## Full-Snapshot DAST Reporting

- Changed DAST reports from a delta-only view to a full snapshot of the application's security posture for each execution.
- Provides an auditable, self-contained record of vulnerabilities identified at scan time.
