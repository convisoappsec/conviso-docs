## Introduction

Release 4.20 strengthened Conviso Platform as a unified AppSec hub, expanding enterprise integrations, developer workflows, security monitoring, and supply-chain visibility.

---

**_New Feature_**
## ServiceNow Integration

- Added native ServiceNow ITSM integration to create and update incidents from Conviso findings.
- Helps security and engineering teams operationalize remediation through established ITSM workflows.

---

**_New Feature_**
## Security Gate and GitHub Pull Request Scanning

- Introduced an in-platform Security Gate experience for monitoring and managing gate runs.
- Added Conviso AST checks and annotations for open GitHub pull requests, moving security feedback earlier into code review.

Learn more in the [Security Gate documentation](https://docs.convisoappsec.com/platform/security-gate) and [GitHub Pull Request Scans documentation](https://docs.convisoappsec.com/integrations/github-pr-scans).

---

**_New Feature_**
## Continuous SBOM Monitoring

- Introduced SBOM correlation to improve consistency between Conviso AST and Platform monitoring.
- Expanded advisory coverage and reduced inconsistent finding lifecycle changes.

Learn more in the [SBOM documentation](https://docs.convisoappsec.com/platform/sbom-management).

---

**_Improvements_**
## DAST and AI Agent Improvements

- Expanded DAST API support for Swagger, GraphQL, and SOAP scenarios.
- Added Auto-Fix capabilities, DAST false-positive review support, and chat usability improvements for AI Agents.

---

**_Improvements_**
## Vulnerability Management and Platform Reliability

- Added bulk actions and improved filtering and navigation in vulnerability workflows.
- Improved scan lifecycle robustness, dashboard reliability, observability, and defect-tracker synchronization visibility.

👉 Access the [Conviso Platform](https://app.convisoappsec.com) to explore these updates.
